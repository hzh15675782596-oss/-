## 📖 关于本项目 (About)

这是一个**单页应用 (SPA)** 形式的个人作品集网站，专为展示我在**新闻传播**与**AI 运营**领域的跨界经历而设计。

网站采用了 **"Tech-Pop" (科技波普)** 的设计语言，旨在体现“硬核科技”与“人文感知”的融合。通过暗黑极客风与高饱和度色彩的碰撞，还原了我在**安克创新 (Anker Innovations)** 推动企业 AI 文化转型的实战场景。

### 核心亮点
*   **双重身份叙事**：从传统的“新闻全媒体人”到新兴的“AI 增长黑客”。
*   **沉浸式体验**：动态粒子背景模拟“风”的流动，象征思维的活跃。
*   **全球化视野**：内置中/英双语无缝切换引擎。

## ✨ 功能特性 (Features)

### 1. 🌗 昼夜双模系统 (Dark/Light Mode)
*   完美适配的**“暗夜极客”**与**“白昼清新”**两种视觉主题。
*   使用 `localStorage` 自动记忆用户偏好，刷新页面不丢失设置。

### 2. 🌬️ 粒子风暴交互 (Particle Wind System)
*   基于 HTML5 Canvas 开发的原生粒子系统。
*   **物理交互**：粒子会随着鼠标的移动轨迹产生“被风吹散”的物理排斥效果，增加浏览趣味性。

### 3. 🌐 i18n 双语引擎
*   默认英文界面，彰显国际化职场定位。
*   一键切换中文，DOM 级实时文本替换，无需页面跳转。

### 4. 🖼️ 影像实验室 (Visual Playground)
*   模拟 CMS 内容管理体验。
*   支持本地图片上传预览，动态生成卡片流，展示 AIGC 创作成果（如 Nano Banana Pro 生成的漫画）。

### 5. 📱 响应式设计
*   基于 **Tailwind CSS** 构建，完美适配 Desktop、Tablet 及 Mobile 端。
*   包含吸顶导航栏 (Sticky Navbar) 与移动端适配布局。

## 🛠️ 技术栈 (Tech Stack)

本项目坚持**“轻量化、高性能”**原则，无繁杂构建流程，即开即用。

*   **结构 (Structure)**: HTML5 Semantic Tags
*   **样式 (Styling)**: Tailwind CSS (Via CDN for rapid prototyping)
*   **脚本 (Logic)**: Vanilla JavaScript (ES6+)
*   **字体 (Typography)**: Google Fonts (Inter & JetBrains Mono)

    *   🟡 Vitality Yellow: `#FFD700` (创意高亮)

## 🚀 快速开始 (Quick Start)

无需安装 Node.js 或 npm，本项目为静态网页，任何浏览器均可直接运行。

1.  **克隆仓库**
    ```bash
    git clone https://github.com/your-username/portfolio-2026.git
    ```

2.  **运行项目**
    *   直接双击打开文件夹中的 `index.html`。
    *   或者使用 VS Code 的 `Live Server` 插件启动预览。
